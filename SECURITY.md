# Lapis Security Policy

## Reporting a vulnerability

Please do not publish an unpatched vulnerability in a public issue. If you
are using the GitHub-hosted Lapis repository, use its **Report a vulnerability**
link under Security to create a private advisory. For another hosting setup,
contact the repository owner or deployment administrator privately.

Include a concise description, steps to reproduce, the affected commit or
version, and the impact you observed. Do not include real user data or live
credentials in a report.

## Scope

Reports about this source tree, its authentication and authorization flows,
data handling, integrations, and deployment guidance are in scope. Self-hosted
deployments are configured by their operators; include the relevant setup
details when reporting an issue.

## Supported versions

The active branch is the supported development version. Security fixes for
older releases depend on the repository owner maintaining them.
